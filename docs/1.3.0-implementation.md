## Verification

Use npm test, npm run test:coverage, npm run lint, npm audit --omit=dev,
npm run build, and npm run test:browser from a committed clean tree.

The extension smoke performs an actual browser download after closing its
initiating page, while provider responses remain synthetic. It also exercises
selection disclosure, hidden focus, preview/export agreement, storage round trips
and concurrent snapshots. Unit tests cover worker-restart download reconciliation,
settings races, source normalization, hash recomputation and credential redaction.

No logged-in provider acceptance or Firefox/Edge runtime acceptance is implied by
these checks. The build verifies packages for Chrome/Edge and Firefox and validates
the source archive against the committed version. Store publishing is separate.

## Branch and workspace policy

AGENTS.md requires beneficial validated changes to be committed and synchronized
to main during the task. Historical branch tips are retained under
`archive/2026-09-15/*`; obsolete branches are removed only after remote tag checks.
See branch-consolidation.md for tree-equivalence evidence.

Keep the installed unpacked mirror and current build artifacts usable. Do not
remove credentials or private local configuration during cleanup. Generated caches
and obsolete package-manager files can be removed or moved to a recoverable local
work archive after final validation.
