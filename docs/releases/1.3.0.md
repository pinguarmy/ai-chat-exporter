# AI Chat Exporter 1.3.0

## 中文

这次更新精简了批量导出界面，增强了引用与归档导出，并修复了设置、预览和后台下载的一致性问题。

### 界面与设置

- 将日期范围、数量等快速选择条件收进可展开面板，高级导出选项按需展开。
- 清楚显示已选、将导出和跳过的数量，导出按钮固定在底部。
- 修复无效日期、数字输入编辑、折叠区域键盘焦点与长内容显示问题。
- 本次导出设置与默认设置分开，可明确保存为默认或重置；预览沿用本次选择。
- 新增完整导出工作页，方便处理较长的 PDF 与“另存为”导出。
- 为新增功能补充简体中文、繁体中文、英语、德语、日语和韩语文案。

### 导出与归档

- 改进 ChatGPT 嵌套引用与实体标签还原，对无法解析的引用显示诊断提示。
- 支持可选消息时间戳，保留来源提供的时间与模型信息，文件名新增短对话 ID 变量。
- 普通 Markdown 批量导出改为后台任务，关闭弹窗后仍可继续；支持停止、中断后恢复与完成记录。
- 新增 ZIP 归档，包含 Markdown、引用、内联产物、文件清单及 SHA-256 校验值。
- 可选导出 ChatGPT 已暴露的工具调用与结果轨迹，以及带常见敏感信息脱敏的分享副本。

### 稳定性与隐私

- 修复预览与实际导出设置不一致、并发设置保存覆盖以及旧列表请求覆盖新结果的问题。
- 修复后台任务恢复时旧下载取消失败可能导致重复下载的问题。
- 加强凭证存储、引用 URL 检查与预览内容清理，隔离内容清理器的临时规则。
- 更新生产依赖并通过安全审计。

### 使用说明

后台恢复需要主动点击继续。PDF 和“另存为”导出仍需保持导出页面打开。ZIP 不下载外部附件；工具轨迹仅包含 ChatGPT 已暴露的事件。分享脱敏不能识别所有隐私信息，分享前请检查。历史去重按对话 ID 判断，不检测对话内容是否更新。

## English

This release simplifies bulk export, improves citations and archives, and fixes inconsistencies in settings, previews, and background downloads.

### Interface and settings

- Collapse date ranges, count limits, and other quick-selection controls into an expandable panel; show advanced options on demand.
- Show selected, exportable, and skipped counts, with the export button kept visible at the bottom.
- Fix invalid-date handling, editable number inputs, keyboard focus in collapsed panels, and clipped content.
- Keep session export options separate from saved defaults, with explicit save/reset controls and matching previews.
- Add a full export workspace for longer PDF and Save As operations.
- Translate new controls into English, Simplified and Traditional Chinese, German, Japanese, and Korean.

### Exports and archives

- Restore nested ChatGPT citations and entity labels, with diagnostics for unresolved references.
- Add optional message timestamps, available time/model metadata, and a short conversation ID filename variable.
- Run ordinary Markdown bulk exports in the background after the popup closes, with stop, resume, and completion tracking.
- Add ZIP archives containing Markdown, references, inline artifacts, a manifest, and SHA-256 checksums.
- Optionally include ChatGPT-exposed tool calls/results and a share copy with common sensitive patterns redacted.

### Reliability and privacy

- Fix preview/export option mismatches, concurrent settings overwrites, and stale conversation-list responses.
- Prevent duplicate downloads when a restarted queue cannot cancel an older active download.
- Harden credential storage, reference URL checks, and preview sanitization; isolate temporary sanitizer rules.
- Update production dependencies and pass the production security audit.

### Usage notes

Interrupted background jobs require explicit resume. PDF and Save As exports still require an open export page. ZIP archives do not download external attachments. Tool traces contain only events exposed by ChatGPT. Redaction cannot identify every private detail; review share copies before sharing. Export history deduplicates by conversation ID, not by content changes.
