# AI Chat Exporter 1.5.0

This version includes the previously unpublished 1.4.2 changes. Publication and store-review status are tracked separately from these release notes.

## 中文

### 更直接的导出流程

- 格式选择改为“可编辑 Markdown / 阅读版 PDF / 归档 ZIP”，不必先寻找 ZIP 的高级开关。高级选项和明确保存默认值的行为保留。
- 从弹窗打开完整工作区时，保留模式、格式、所选会话、搜索、快捷选择条件和本次临时选项。交接仅存浏览器会话内存，有时限且不包含聊天正文。无法交接时保留原选择并明确提示，不偷偷重置。
- 后台批量显示具体失败会话和原因，可只重试失败项；仍支持继续剩余任务。按钮与摘要显示实际将导出的数量。
- 下载完成显示浏览器确认的实际文件名，包括重名自动编号，并可打开下载文件夹。普通预览也支持取消和完成收据。取消不会显示导出成功，也不会锁住重试按钮。
- 占位标题在检测时统一确定，当前导出、预览和保存前文件名保持一致；新后台任务会清除前次结果，当前会话的文件编号预览与下载一致。
- 重新捕获快照失败会显示错误和旧快照时间，旧快照仍可保存。
- 新增可随时重看的快速上手，提供真实平台链接、返回扩展步骤、格式用途和保存位置说明，不弹强制欢迎页或引入账号。
- 预览入口明确提示可选消息；批量格式选择常驻底部，保存前显示目的地及设置入口，分享模式的预计文件名与输出一致。
- 未验证的来源先解释快照限制，仅提供 Markdown/PDF，主按钮明确保存快照。只捕获不下载的入口另行折叠，避免重复动作混淆。
- 补齐德、日、韩的主要导出按钮与状态翻译，改善暗色按钮文字对比；键盘、六语、真实首次下载和文件名收据纳入浏览器检查。

### 按消息选择

- 预览可切换全部消息、勾选消息、最后一条 AI 回答。复制、Markdown 和 PDF 使用相同选择与原始顺序。
- 部分导出始终声明保存了多少条、原来有多少条，即使关闭元数据也不隐藏说明。文件名带 selected/last-answer 后缀。
- 部分导出不生成完整 ZIP、不包含原始 provider 数据、整段工具轨迹或不属于选择范围的独立产物，也不会进入完整归档去重记录。
- 页面快照同样支持选择，仍保留原捕获身份和“未验证完整历史”的声明。
- 分享副本在预览、复制、普通 Markdown 和 PDF 中使用一致的常见凭据隐藏规则；移除附件/引用的目标链接和原始 provider 数据。它不是匿名化，姓名、私人叙述和未识别的密钥仍需人工检查。
- 二轮复审修复 ZIP 内资源文件名、模型元数据、自定义 AI 标签和后台批量文件名的凭据遗漏。分享文件不再采用脱敏设置更新前的 Markdown 缓存。
- “创建分享副本”在 Markdown、PDF 和 ZIP 中始终可控制；关闭引用时不再因分享处理重新带出引用标题。

### 内容正确性与适配

- ChatGPT 的 code/execution_output 工具正文不再因为不在 content.parts 内而被导为空。不采集隐藏思考。
- DeepSeek 按 current_message_id 与 parent_id 选择当前分支并保留根到叶的顺序。断链、循环、重复身份或没有分支证据时，不认证为完整对话。
- Grok 的 partial/inflight 回答不再被认证为已完成归档。
- DeepSeek 和 Grok 从已确认响应字段保存公开网页来源，沿用标题/公开链接/关闭引用等隐私选项；不导出搜索查询、摘要或隐藏思考。
- Claude 从已确认的 display_content.json_block 结果中保留 HTML、Markdown、SVG 的展示源文本。代码作为惰性文本保存，不运行脚本，不宣称捕获整个交互应用。
- 弹窗和预览列出当前输出中的消息、引用、附件标签和内联产物数，并说明缺少正文的产物、不可用图片、外部文件和交互界面的边界。
- 关闭代码时，预览、Markdown、PDF 和 ZIP 均排除独立代码产物。范围摘要保留快照实际输出的图片标签，PDF 不再显示 ZIP 专属说明。

### 隐私与依赖

- 修复测试样本脱敏器漏处理嵌套 JSON、Gemini RPC 字符串、位置数组及搜索/工具内容的问题。未知文本默认替换；仅保留有限公共协议枚举，未知 Gemini transport 拒绝处理。重新清理当前五个平台的样本。
- 当前文件清理不移除 Git 历史、旧发布资产或缓存副本。历史暴露范围与远端副本处理需要维护者单独评估，不将本次修复称为历史已清除。
- DOMPurify 更新为 3.4.17。预览和完成记录均不转存原始 provider payload。

### 包含此前未发布的修复

Claude 上传文本及纯附件消息保留、ChatGPT 纯图片占位、代码缩进、自动快照回退、恢复草稿保留及可选扩容、定时重复读取与显式同名覆盖、最后消息时间文件名、静态 ChatGPT 状态卡片、六语字体与帮助反馈入口。详细行为见 [此前开发记录](1.4.2.md)。

## English

### Export workflow

- Choose Editable Markdown, Reading PDF or Archive ZIP directly. Advanced settings remain available and session changes still require an explicit action to become defaults.
- Carry mode, format, selected conversations, search, selection rules and temporary options into the full workspace. The handoff is short-lived browser-session storage without conversation text. A failed handoff keeps the existing selection and shows a clear error.
- Background jobs show failed titles and categories, retry only failures, and retain Resume remaining. Export counts reflect eligible conversations rather than only selected rows.
- Show the browser-confirmed filename, including native duplicate numbering, and open the download folder. Ordinary previews also support cancellation and completion receipts. Cancellation is distinct from success and never locks the retry action.
- Resolve placeholder titles once before quick export, preview and filename preflight. New background jobs clear old outcomes, and current-chat index tokens agree with downloads.
- Failed recaptures show the error and the retained capture time instead of silently presenting old content as fresh.
- Add reopenable Quick start with real provider links, return-to-extension instructions, format purposes and file destinations. No forced welcome tab or exporter account.
- Name message selection in the preview entry, keep bulk format choices visible, and show the destination before saving. Share-mode filename receipts match the prepared output.
- Explain snapshot limits before saving unverified content, offer only Markdown/PDF, and separate optional capture-without-downloading controls.
- Complete primary German/Japanese/Korean actions and improve dark button contrast. Keyboard, six-locale guidance and a native first-download filename check run in the browser suite.

### Message selection

- Preview all messages, select individual messages, or export the last assistant answer. Copy, Markdown and PDF preserve the same selection and source order.
- Partial files have a mandatory scope notice and a selected/last-answer filename suffix. They never become complete archives or enter duplicate-protection history.
- Partial exports omit raw provider payloads, conversation-wide tool events and unrelated artifacts. Page snapshots retain their original capture notice and unverified-history status.
- Share copies consistently redact common credentials in rendered preview, copy, standalone Markdown and PDF. Attachment/reference targets and raw provider data are omitted. This is heuristic redaction, not anonymization; review names, private prose and unrecognized secrets before sharing.
- A second review fixed credentials in ZIP entry names, model metadata, custom assistant labels and background bulk filenames. Share downloads ignore Markdown cached before redaction settings changed.
- The share-copy switch remains editable for Markdown, PDF and ZIP. Disabling references stays disabled during share preparation, including page snapshots.

### Correctness and captured content

- Preserve ChatGPT code/execution_output tool bodies stored in content.text without collecting hidden reasoning.
- Resolve DeepSeek's selected parent chain. Broken/cyclic/duplicate or unproven branch structures are not marked complete.
- Do not verify Grok partial or in-flight responses as finished transcripts.
- Preserve public web-source metadata from confirmed DeepSeek and Grok response fields under the existing reference privacy policy. Search queries, previews and hidden thinking are not exported.
- Preserve Claude HTML, Markdown and SVG display source from the observed display_content.json_block shape as inert text. This does not run or replay an interactive application.
- Show represented message/reference/attachment/artifact counts and disclose missing bodies, unavailable images and external-resource limitations.
- Disabling code excludes separate code artifacts consistently from preview, Markdown, PDF and ZIP. Coverage counts retain snapshot image labels that remain in the file; PDF does not show ZIP-only guidance.

### Privacy and dependencies

- Sanitize nested JSON, Gemini RPC transport/positional arrays and search/tool text before committing provider fixtures. Unknown text is replaced, public protocol values use a finite allowlist, and unknown Gemini transport is rejected. The current five fixtures were sanitized again.
- Cleaning the current tree does not remove old Git objects, published archives or cached copies. Historical exposure and remote-asset remediation remain a separate maintainer decision.
- Update DOMPurify to 3.4.17. Raw provider payloads are excluded from preview and completion-history messages.

The release also includes all previously unpublished [1.4.2 improvements](1.4.2.md).

## Verification and release gates

See the [executed candidate verification](../1.5.0-verification.md), then run the canonical [release checks](../release-workflow.md) on the final committed tree. Tests and Chromium synthetic downloads do not prove current provider integrations work.

The maintainer authorized publication on 2026-11-09 without accessing logged-in provider sessions. All five live-provider acceptance checks and Firefox/Edge runtime acceptance remain outstanding. Publication does not change those limits or imply the earlier all-dimensions quality target was met. Store review and public availability must be confirmed per channel. Historical asset deletion remains outside this release.

Interactive ChatGPT Apps, Gemini Canvas/Dynamic View, new Claude Artifacts files/versions, Grok Build state and remote connector data are not guaranteed to be captured. Existing static cards and captured source text are not a pixel-perfect or executable offline copy. Weekday/hour scheduling from draft PR #29 is not included.
