# AI Chat Exporter 1.4.1

## 中文

这是一个修复版本。1.3.0 和 1.4.0 里，Claude 对话的单条导出、批量导出和定时导出都会被“导出验证失败”拦住，这次修好了。验证没通过时，现在也不会只给一个报错。

### 修复

- Claude 导出被错误拦截：Claude 每段对话第一条消息都带一个固定的占位父节点，旧版本把它当成了缺失的消息，判定对话不完整后停止导出。现在能正常识别，验证通过的对话照常导出。真正缺消息的对话仍然会被拦住，不会导出残缺文件。
- 同一个 Claude 账号有多个组织（比如个人订阅加机构席位）时，如果当前页面所属的组织打不开这段对话，会去试账号下的其他组织，不再直接当成没登录。

### 改进

- 验证失败时可以保存页面快照：ChatGPT、Claude、DeepSeek 和 Grok 也支持页面快照了。完整来源没法验证时，弹窗会直接给出“捕获页面快照”，把页面当前已经加载的内容保存下来。快照会标明不是完整存档。
- Gemini 关闭历史记录时点导出，现在会提示改用页面快照。
- 本地恢复草稿仍然只支持 Gemini。

### 使用说明

页面快照只包含页面已经加载、可以读取的内容，需要完整历史时请使用常规导出。

## English

A fix release. In 1.3.0 and 1.4.0, single, bulk and scheduled exports of Claude conversations were stopped with "Export verification failed". That is fixed, and a failed verification no longer ends with only an error.

### Fixes

- Claude exports were wrongly refused. Claude gives the first message of every conversation a fixed placeholder parent, which earlier versions treated as a missing message, so the conversation was judged incomplete and the export was stopped. It is now recognised and verified conversations export normally. Conversations that really are missing messages are still stopped, so no truncated file is saved.
- When one Claude account belongs to several organizations (for example a personal plan and an institutional seat) and the page's organization cannot open a conversation, the other organizations are tried instead of treating the account as signed out.

### Improvements

- Page snapshots when verification fails: ChatGPT, Claude, DeepSeek and Grok now support page snapshots too. When the full source cannot be verified, the popup offers Capture page snapshot to save what the page has loaded. Snapshots are labelled as not being a complete archive.
- Exporting from Gemini with history turned off now points you to the page snapshot.
- Local recovery drafts remain Gemini only.

### Notes

A page snapshot contains only what the page has loaded and can read. Use the regular export when you need the full history.

## Packages

- `ai-chat-exporter.zip`: Chrome / Edge
- `ai-chat-exporter-firefox.zip`: Firefox
- `ai-chat-exporter-source.zip`: source for AMO review, not an installable extension
