# AI Chat Exporter 1.4.0

## 中文

这次更新新增 Gemini 页面快照，加强了导出和下载的恢复能力，并更新了两个有安全公告的依赖。

### 新功能

- Gemini 页面快照：在弹窗里选择“保存页面快照”，把当前页面已经加载、可以读取的对话保存下来。关闭 Gemini 历史记录、没法做完整导出时也能用。快照只包含捕获时页面上的内容，会明确标为快照，不会当作完整归档。可以复制或保存为 Markdown，也可以在预览里下载 PDF。
- 可选的本地恢复草稿：默认关闭。为某个对话开启后，扩展会在本机保存页面变化，浏览器崩溃后可以在恢复页面里找回、下载或删除。单个草稿最多 1 MiB，总共 4 MiB、20 个，最多保留 7 天。
- 文件名默认加上 8 位对话 ID，同一天同名的对话不再互相覆盖。
- ZIP 归档可以选择附带平台原始数据（raw-provider.json.gz），分享副本里永远不包含。
- 商店名称和简介新增简体中文、繁体中文、日语、韩语和德语版本。

### 改进与修复

- ChatGPT 生成过程中留下的中间草稿，确认属于同一个回答后会合并为最终版本（可以关闭）。
- 导出历史和下载记录在浏览器重启或扩展更新后也能恢复；超时的下载会被取消，不会重复下载。完整性信息和草稿元数据会保留。
- 弹窗里的提示不再被边缘截断；中文等界面的选项不再挤成一列；导出按钮会直接显示将生成的文件类型和文件名。
- 各平台的报错改为本地化提示；在平台首页使用批量导出时，历史列表单独加载，不受当前页面读取失败的影响。
- 文件名会去掉零宽字符和双向控制字符，避免文件名被伪装。

### 安全

- DOMPurify 更新到 3.4.16，KaTeX 更新到 0.18.10，均修复了已公开的安全问题。

### 使用说明

页面快照目前只支持 Gemini，只保存页面已加载的内容；需要完整历史时请使用常规导出。本地恢复草稿只保存在本机，不会同步到云端。分享脚敏不能保证识别所有敏感信息，分享前请检查。

## English

This release adds Gemini page snapshots, makes export and download recovery more durable, and updates two dependencies with published security advisories.

### New

- Gemini page snapshots: choose Capture page snapshot in the popup to save the conversation content already loaded and readable in the current page, even when Gemini history is off and a full export is not possible. A snapshot contains only what the page showed at capture time, is labelled as a snapshot, and is never treated as a complete archive. Copy or save it as Markdown, or download a PDF from its preview.
- Optional local recovery drafts, off by default. When enabled for a conversation, the extension keeps page observations on this device so you can find, download or delete them on the recovery page after a crash. Up to 1 MiB per draft, 4 MiB and 20 drafts in total, kept for up to seven days.
- Default filenames include an 8-character conversation ID, so same-day conversations with the same title no longer overwrite each other.
- ZIP archives can optionally include the raw provider response (raw-provider.json.gz); it is never included in share copies.
- Store name and summary in Simplified Chinese, Traditional Chinese, Japanese, Korean and German.

### Improvements and fixes

- ChatGPT streaming drafts are merged into the final answer once they are confirmed to belong to the same answer (can be turned off).
- Export history and download records survive browser restarts and extension updates; timed-out downloads are cancelled instead of being downloaded twice. Completeness and draft metadata are preserved.
- Popup tooltips are no longer clipped, option rows no longer collapse in Chinese and other CJK interfaces, and the export button shows the real file type and filename.
- Provider errors are localized; bulk history on a provider home page loads on its own and is not blocked by a failed page read.
- Zero-width and bidirectional control characters are removed from filenames so a name cannot be disguised.

### Security

- DOMPurify updated to 3.4.16 and KaTeX to 0.18.10, both fixing published security issues.

### Notes

Page snapshots currently support Gemini only and save only content the page has loaded; use a regular export when you need the full history. Recovery drafts stay on this device and are not synced. Share-copy redaction cannot guarantee that every secret is removed; check before sharing.
