# 页面快照与恢复界面简报

产品：AI Chat Exporter。范围：既有弹窗中的快照面板、固定预览与本地恢复页。

方向：沿用现有中性文档界面，不重新设计整个扩展。快照是备用保存动作，不和完整归档争抢主按钮。

- 布局：弹窗中一块紧凑面板，先捕获，再展示时间、范围和保存动作；恢复设置单独折叠，避免长隐私说明挤走保存按钮。
- 识别特征：固定的“页面快照／未验证完整历史”说明；完整归档与快照不共用成功标记。
- 色彩与字型：继承现有 CSS 变量和系统字体；危险删除使用明确红色，恢复成功时间保持普通文字，不用安全盾牌暗示保证。
- 内容：真实捕获时间、消息数、生成状态和最近成功检查点。不使用装饰指标、渐变或示例私聊。
- 操作顺序：捕获 → 快速 Markdown／复制；预览及 PDF 是可选动作。PDF 在稳定页面显示下载进度与取消。
- 动效：仅继承已有反馈，避免背景观察器驱动持续闪烁；支持 reduced motion。
- 无障碍：语义按钮、错误 alert、保存 status、清晰键盘 focus；删除采用可访问的确认区，不伪装为未实现焦点管理的模态窗。
- 验收：窄弹窗与六语言不横向溢出；长标题、范围说明与恢复错误可换行；停止保护和删除数据分开。
- 不在范围：主题重构、营销页、原有批量导出重排。
