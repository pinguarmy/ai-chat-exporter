# 1.5.0 candidate verification

This is a candidate engineering record, not a store-publication result. No provider login was used. The maintainer explicitly deferred access to logged-in sessions.

## Executed on 2026-11-04

- Installed the lockfile with npm 10, matching the CI npm major. DOMPurify 3.4.17 is installed.
- The integrated coverage run passed 110 files and 1,239 tests. The existing coverage gate applies to four core contract modules, not the entire application.
- TypeScript passed. The production dependency audit reported zero vulnerabilities. The independent feedback backend passed 12 tests.
- Chrome/Edge, Firefox and source-review ZIPs were built from a clean committed tree. Both manifests and the source package report 1.5.0; ZIP integrity checks passed.
- Built Chromium smoke passed real Markdown, PDF and ZIP downloads, session handoff, background completion after page closure, page snapshots, recovery, static cards and native scheduled overwrite/opt-out behavior.
- The new workspace test clicks the actual popup entry and verifies restored PDF format, selected conversation, selection rules and temporary options.
- The new partial test uses duplicate message IDs, selects one message by source position, compares the actual clipboard and Markdown, downloads a real PDF, and confirms that complete-export history did not change.
- PDF text extraction confirmed the selected answer and mandatory partial notice were present, and both unselected messages were absent. A 375px screenshot was inspected after fixing action-toolbar wrapping. Six-locale popup screenshots were checked for horizontal overflow and action visibility.
- Privacy fixtures were sanitized again using the repaired tool. It rejects unknown Gemini transport and replaces unknown text. A clean residual-credential scan is not a proof that no private information can remain.

The first browser attempts exposed two test-harness issues, a non-unique footer locator and an unsupported extension-origin permission grant. Both were corrected. A subsequent genuine 375px toolbar overflow was fixed in the product CSS, rebuilt and retested. The final browser suite passed; failed attempts are not counted as successful verification.

## Second review, 2026-11-04

This review is limited to the new 1.5.0 export and workflow paths. Provider parsers, transport contracts, permissions and dependencies were not changed. Current logged-in integrations remain untested.

Synthetic regressions first reproduced these failures, then passed after minimal fixes:

- Shared ZIP entry names and manifest model labels could retain recognizable credentials even when body text was redacted. Entry names and model labels now use the same redaction before file paths and hashes are finalized.
- Custom assistant labels and caller-supplied cached Markdown could bypass share handling. Preview and output labels now agree, and share downloads regenerate Markdown from the current settings.
- Share preparation overrode reference opt-out with titles, including page snapshots. Opt-out now remains off through preview, copy, Markdown, PDF, ZIP and coverage counts.
- The share-copy switch disappeared outside ZIP although the setting still affected PDF and Markdown. It now stays in the common content options and appears only once in ZIP.
- Separate code artifacts bypassed the code toggle in Markdown and HTML/PDF. The common artifact filter now matches ZIP and coverage. Snapshot labels retained with image rendering disabled are counted, and PDF no longer shows ZIP-specific coverage text.
- Background manual bulk downloads constructed filenames from the unredacted title. Filenames now use the prepared share copy while completion history keeps the authoritative provider ID. Scheduled backups retain their existing separate policy; this review does not add share mode to them.

The final integrated check passed 111 files and 1,253 tests, TypeScript, the production audit and the 12 feedback backend tests. The built-extension check additionally inspects real shared ZIP entry names and contents for synthetic credential sentinels, parses every JSON payload, checks manifest paths/lengths/hashes, and exercises the share switch in PDF and plain Markdown.

## Regression boundaries

- ChatGPT code/execution_output text is preserved in exposed tool records. Unknown text-bearing tool types do not gain a broad fallback into hidden reasoning.
- DeepSeek requires a selected, rooted parent chain. Missing parents, cycles, duplicate IDs and absent branch evidence do not verify.
- Grok nonempty in-flight arrays or partial responses remain unverified.
- Partial exports cannot construct complete archives, register complete-history entries, include raw provider data or use stale caller-provided Markdown without the mandatory notice.
- Share copies are applied consistently to rendered preview, clipboard, Markdown and PDF. Full downloads retain authoritative IDs for archive history; raw provider payloads are stripped from completion messages. Redaction remains heuristic, not anonymization.
- Claude display source remains escaped, inert text. Search-source metadata does not include queries, previews or hidden thinking.
