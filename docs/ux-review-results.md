# 1.5.0 onboarding and experience review

Scope and weights are frozen in [the rubric](ux-review-rubric.md). Scores are independent model expert assessments, not user-study results or proof of live-provider compatibility. Do not substitute a previous candidate's score for a later build.

## Baseline, product commit 9b54b26

The baseline uses a fresh isolated Chromium extension profile and blocked provider network access. Only provider-tab replies are synthetic. Actual UI, extension storage and a real first Markdown download were inspected. Evidence was generated by the UX scenario script; existing selection/share and six-locale screenshots supplement it.

Terra's material findings: unsupported-page guidance has no actionable provider links or return/save instructions; message selection is hidden behind a generic preview label; the pre-download receipt lacks destination and format explanation; an existing-but-unverified conversation can silently switch to snapshot output before explaining the alternative. Accessibility and recovery need direct scenario evidence, not only screenshots.

Live provider sessions, Firefox/Edge runtime and actual first-time user observation remain outside these scores and must be reported as unverified.
