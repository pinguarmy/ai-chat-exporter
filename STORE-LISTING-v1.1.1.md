## Detailed Description

```
AI Chat Exporter is the free, open-source way to save your AI conversations from ChatGPT, Gemini, Claude, DeepSeek, and Grok as clean PDF or Markdown files.

No paywalls. No subscriptions. No extension accounts. No analytics. Your conversations stay under your control.

Use it for personal archives, research notes, coding sessions, class materials, and long-running projects you want to keep outside a single chat platform.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

SUPPORTED PLATFORMS
• ChatGPT (chatgpt.com)
• Google Gemini (gemini.google.com)
• Claude (claude.ai)
• DeepSeek (deepseek.com)
• Grok (grok.com)

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

KEY FEATURES

✅ 100% Free & Open Source
Export your AI chats without paid tiers, subscription prompts, or account creation. The code is public and MIT licensed.

🚀 One-Click Export
Export the conversation you're currently viewing to PDF or Markdown instantly. No copy-pasting, no formatting lost.

📦 Bulk Export
Export all your conversations at once. The extension fetches your full conversation list from the platform's API and lets you download everything in one go. Advanced options available: filename templates, content toggles, and more.

👁️ Live Preview
See exactly what your export will look like before downloading. Toggle between rendered chat bubbles and raw markdown view. Copy to clipboard with one click.

🌙 Dark & Light Mode
Full dark theme with system preference detection. Toggle instantly from the popup header or settings page. Your preference syncs across all pages.

🌐 Multi-Language UI
Switch between English, 简体中文, and 繁體中文 in Settings → General & Appearance. All UI text updates instantly.

📄 Beautiful PDF Output
PDFs preserve conversation structure with proper formatting:
• Headings, bold, italic, and inline code
• Code blocks with syntax highlighting
• LaTeX/mathematical equations
• Bullet lists and numbered lists
• Blockquotes
• Page breaks that don't cut content in half

📝 Clean Markdown Export
Markdown files preserve the original formatting with:
• Proper paragraph breaks
• Code blocks with language tags
• LaTeX equations preserved as-is
• Metadata header (platform, URL, date, message count)

🏷️ Custom Filenames
Choose from multiple filename templates:
• {date} — Export date
• {datetime} — Export date and time
• {title} — Conversation title
• {platform} — Platform name (ChatGPT, Claude, etc.)
• {conv_date} — Conversation start date
• {end_date} — Conversation end date
• {msgcount} — Number of messages
• {index} — Message index

📁 Smart Folder Organization
Organize exports by platform, custom folder, or save to root:
• Default: Save to Downloads root
• By Platform: Auto-sort into ChatGPT/, Claude/, Gemini/, etc.
• Custom Folder: Use any folder name you want (Unicode supported)

⏰ Scheduled Auto-Export
Automatically backup new conversations in the background. Set per-platform schedules (hourly, every 6 hours, daily, weekly). The extension scans silently and saves new chats as Markdown — no manual intervention needed.

🔍 Full Conversation Capture
The extension uses the platform's own API to fetch complete conversations, not just what's visible on screen:
• All messages captured (not just what's scrolled into view)
• Assistant responses preserved with full formatting
• Code blocks, artifacts, and attachments included
• Conversation metadata (title, date, platform) included

⚙️ Settings & Customization
• Default export format (PDF or Markdown)
• Filename template with live preview
• Include/exclude metadata, code blocks, images, uploaded files
• Download folder organization
• Theme preference (light/dark)
• Language selection (EN / 简体中文 / 繁體中文)

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

PRIVACY & SECURITY
• 100% free — no paid export caps, subscriptions, or extension accounts
• No data collection — your conversations never leave your browser
• No analytics or tracking — zero telemetry
• No extension-operated servers — export processing happens locally
• Platform API requests are made only to the AI services you are already using
• No accounts or sign-ups required
• Open source — audit the code yourself on GitHub
• Minimal permissions — only what's needed to export
```
